Core Asynchronous Pipeline Execution Flow Sprint INF-01 / INF-02 / DAT-01 
1. Initiation        Founder submits deck via POST /pitches/upload -> Persisted to Postgres (status: PENDING)
2. Event Publication Emits payload to Kafka topic: startup.pitches.submitted & pitch.registered
3. Worker Ingestion  Consumer worker picks event from group arovia-dealflow-group
4. Live Broadcast    Pushes dealflow ping to Angel Investors via /ws/notifications & logs to audit_logs
5. Deal Closure      Investor makes term sheet & executes POST /ledger/commitments with ACID Cap Table update
